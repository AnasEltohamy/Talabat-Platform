About the project

Talabat is a learning-to-production e-commerce platform. The back-end follows the Onion Architecture with the Repository, Unit of Work and Specification patterns, which keeps the business logic independent from the database and the web layer. The Angular client talks to the API through a clear contract and handles authentication, basket, checkout and orders.
